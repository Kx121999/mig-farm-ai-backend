MIG FARM AI V20 — PRODUCT INTELLIGENCE SALES BRAIN MAX

الهدف
تحويل كل كتالوج MIG FARM في Odoo إلى طبقة معرفة منتجات كاملة داخل عقل موظف المبيعات، مع إبقاء السعر والتوفر الحاليين من Odoo Live فقط.

ما تم إضافته
- 704 Product Dossiers — ملف معرفي لكل منتج في الكتالوج.
- 704/704 منتج لديهم Sales/eCommerce Description محفوظة.
- 502 وصف أصلي محفوظ كما هو من ملفات المنتجات القديمة.
- 202 وصف مكمل ثنائي اللغة من ملف استكمال الوصف، مع سياسة عدم اختراع مواصفات تقنية.
- 1410 مقطع Retrieval للبحث داخل الديسكريبشنات بالمعنى والكلمات والـSKU والتصنيف والـTags.
- طبقة Product Intelligence جديدة بحجم 7.14 MB تقريبًا.
- إجمالي ملفات المعرفة الموجودة داخل Release حوالي 12.23 MB غير الكود والاختبارات.

المعلومات المحفوظة لكل منتج
- External ID
- اسم المنتج
- SKU / Internal Reference
- التصنيف
- Supplier / Type / Feature Tags
- Sales Description كاملة

- الوزن

- aliases + semantic retrieval chunks
- provenance للوصف: original_502 أو generated_202

قاعدة الدقة
- السعر الحالي والمخزون الحالي: Odoo Live هو المصدر الأعلى دائمًا.
- وصف المنتج والمواصفات: Product Dossier هو المصدر الموثق.
- إذا المواصفة غير موجودة داخل الديسكريبشن/الداتا، الشات لا يخترعها.
- لا يتم اعتبار منتجات نفس التصنيف متطابقة في المواصفات.
- جرعات المبيدات والأسمدة تظل Label / verified product data only.

- Live catalog results يتم إثراؤها بملخص Dossier عند وجود تطابق.
