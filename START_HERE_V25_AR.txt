MIG FARM AI — V25 AUTONOMOUS SALES & LEARNING OS
=================================================

ابدأ من هنا
-------------

1) ارفع محتويات هذا المجلد إلى جذر مستودع GitHub الحالي.
2) وافق على استبدال الملفات التي تحمل نفس الاسم. لا تمسح المستودع ولا تاريخ Git.
3) أضف متغيرات Vercel المطلوبة من ملف .env.example.
4) أعد نشر مشروع Vercel ثم افتح /api/health وتأكد أن version = 25.0.0.
5) في Odoo استبدل كود واجهة الشات بمحتوى:
   ODOO_CHAT_UI_V25_AUTONOMOUS_SALES_LEARNING_OS.txt
6) امسح كاش المتصفح أو اضغط محادثة جديدة؛ V25 يستخدم مفاتيح جلسة جديدة تلقائيًا.

الملفات القديمة
---------------

- اترك نسخ V22 وV23 وV24 الموجودة؛ هي توثيق واختبارات رجعية ولا تمنع تشغيل V25.
- الملف الذي يجب وضعه في واجهة Odoo الآن هو ملف V25 فقط.
- لا ترفع ملف ZIP داخل جذر التطبيق إذا كنت سترفع محتوياته أصلًا.

ما الذي تغير فعليًا؟
---------------------

- «ما اسمك؟ / شو اسمك؟ / كيفك؟» أصبحت أسئلة معزولة عن أي منتج أو جرعة قديمة.
- رد المقارنة والسعر والتوفر لم يعد يختفي خلف جملة «وجدت منتجات».
- الردود الطويلة أصبحت فقرات وعناوين وقوائم آمنة بدل كتلة نص مزدحمة.
- اتجاه أسماء المنتجات المختلطة عربي/إنجليزي والسعر AED أصبح ثابتًا.
- نموذج تأكيد داخل المحادثة لمسودة عرض السعر وطلب التواصل وتتبع الطلب.
- Odoo لا يُعدل إلا بعد تأكيد صريح ورقم إجراء مطابق للجلسة.
- محرك تقييم ذاتي يسجل درجات وأسباب مجمعة بدون حفظ نص الرسائل أو بيانات التواصل.

مهم جدًا
---------

إجراءات Odoo مقفولة افتراضيًا. اقرأ ODOO_ACTIONS_V25_SETUP_AR.md قبل تفعيل
ODOO_ACTIONS_ENABLED=true. بدون هذه المتغيرات سيوقف النظام التنفيذ بأمان ولن يدّعي
أن الطلب تم.

أوامر الفحص
------------

npm run validate
npm test
npm run release:check
