MIG FARM V8 - PHASE 1 (STAGED UNDER V7)

الهدف:
- تحسين ترتيب نتائج المنتجات بدون تغيير واجهة الشات الحالية.
- جمع Metrics مجمعة بدون تخزين نص رسائل العملاء.
- إضافة Endpoint داخلي محمي للمقاييس.
- عدم تغيير VERSION الظاهر للعميل قبل نجاح الاختبارات النهائية.

ارفع بالترتيب:
1) lib/ranker.js          (ملف جديد)
2) lib/metrics.js         (ملف جديد)
3) استبدل lib/catalog.js
4) استبدل lib/learning.js
5) api/metrics.js         (ملف جديد)
6) tests/v8_core.mjs      (ملف جديد)

لا تعدل api/chat.js ولا api/health.js في هذه المرحلة.

بعد الرفع:
- V7 يظل ظاهرًا للمستخدم.
- الـRanking الجديد يعمل تلقائيًا لأن catalog.js يستدعي ranker.js.
- الـMetrics تبدأ تلقائيًا لأن learning.js يسجلها.
- /api/metrics لن يعرض أي بيانات إلا بعد إضافة Environment Variable:
  MIG_METRICS_TOKEN=<secret value>

مهم:
الـMetrics Runtime aggregate داخل Vercel serverless، لذلك قد تُصفّر عند Cold Start.
هي مناسبة الآن لمراقبة الاتجاهات والاختبار، وليست Database دائمة.
