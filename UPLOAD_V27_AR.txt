رفع V27 على GitHub وVercel

الطريقة الموصى بها: GitHub Desktop

1. احتفظ بنسخة V26 كـ Release أو Backup، ولا تحذفها نهائيًا.
2. افتح مجلد المشروع المحلي المرتبط بـ GitHub.
3. استبدل محتوياته بمحتويات مجلد V27 بعد فك الضغط.
4. تأكد أن knowledge_v27/packs يحتوي 23 ملف JSONL.
5. Commit باسم:
   MIG FARM AI V27 Customer Brain & Decision OS
6. Push إلى GitHub.
7. انتظر نشر Vercel ثم افتح /api/health.
8. إذا ظهر الإصدار 27.0.0 وحجم المعرفة 400MB وfunction_bundle = manifest_router_only فالنشر صحيح.
9. في Odoo استبدل واجهة الشات بملف:
   ODOO_CHAT_UI_V27_CUSTOMER_BRAIN_DECISION_OS.txt
10. امسح كاش الصفحة واختبر جلسة جديدة.

اختبارات سريعة بعد النشر:

- مكانكم فين وهل خيار وفرة متوفر وبكام؟
- الدفع إزاي والشحن بكام؟
- إنت مين ومكانكم فين؟
- عايز تفاصيل المنتج وجرعته كام؟
- عندي اصفرار في الطماطم ومشكلة ري وجذور

لا تضع مفاتيح API داخل GitHub. المتغيرات السرية تظل في Vercel Environment Variables فقط.

مهم: لا تحذف .vercelignore. هذا الملف يمنع حزم الـ400MB من الدخول إلى Vercel Function. الكود يحمل الحزمة المطلوبة فقط من GitHub ويتحقق من حجمها وSHA-256 قبل استعمالها.
