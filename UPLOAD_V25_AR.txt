رفع V25 إلى GitHub وVercel وOdoo
================================

GitHub
------

- لا تمسح كل ملفات المستودع.
- فك الضغط وارفع محتويات مجلد V25 إلى جذر المستودع الحالي.
- اختر Replace للملفات المتطابقة، واترك الملفات التاريخية التي لا يوجد بديل لها.
- تأكد أن package.json في الجذر يحمل version 25.0.0.

Vercel
------

- اربط نفس مستودع GitHub؛ لا تنشئ مشروعًا جديدًا إلا إذا كنت تريد بيئة تجريبية منفصلة.
- أضف القيم من .env.example في Project Settings → Environment Variables.
- OPENAI_API_KEY اختياري للرد العصبي؛ النظام الحتمي يعمل بدونه.
- UPSTASH Redis اختياري لكنه موصى به لاستمرار الجلسات بين نسخ الخادم.
- متغيرات ODOO_ACTION_* مطلوبة فقط للتنفيذ المباشر، وهي مقفولة افتراضيًا.
- بعد الحفظ نفّذ Redeploy.

Odoo Website
------------

- افتح الـView الذي يحتوي كود الشات.
- استبدل الكود كاملًا بمحتوى ODOO_CHAT_UI_V25_AUTONOMOUS_SALES_LEARNING_OS.txt.
- احفظ ثم حدّث الصفحة تحديثًا قويًا Ctrl+F5.
- ظهور النص «يفهم كلامك • ينفذ بموافقتك • يتعلم من النتيجة» يؤكد أن واجهة V25 محملة.

فحص سريع بعد النشر
------------------

1) اكتب: ما اسمك
   المتوقع: تعريف قصير باسم MIG FARM AI بدون كلام عن جرعة أو منتج قديم.

2) اعرض «خيار وفرة»، اختر منتجين ثم قارن السعر.
   المتوقع: يظهر ملخص المقارنة الحقيقي ثم الكروت؛ لا يُستبدل الملخص بعدد المنتجات.

3) اختر منتجًا ثم اكتب: عايز عرض سعر
   المتوقع: نموذج مراجعة الكمية والاسم والهاتف والموافقة.

4) قبل إعداد Odoo Actions، حاول التأكيد.
   المتوقع: رسالة توقف آمنة بدون ادعاء إنشاء الطلب.

5) افتح /api/health
   المتوقع: version 25.0.0 وmode autonomous_sales_learning_agent_os_v25.
