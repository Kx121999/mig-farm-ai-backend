Vercel Environment Variables — V12
===================================

الموجودة عندك وتظل كما هي:
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-5.6            (اختياري إذا كنت تستخدم القيمة الافتراضية)

لتفعيل Persistent Cognitive Memory فعليًا أضف Redis REST واحدًا من Upstash/Vercel-compatible Redis:
UPSTASH_REDIS_REST_URL=https://...
UPSTASH_REDIS_REST_TOKEN=...

أو لو التكامل أنشأ أسماء Vercel KV القديمة، الكود يدعم أيضًا:
KV_REST_API_URL=...
KV_REST_API_TOKEN=...

مهم جدًا:
PERSISTENT_MEMORY_SALT=<random-long-secret>

اختياري:
PERSISTENT_MEMORY_TTL_SECONDS=2592000
القيمة الافتراضية = 30 يوم.

لتفعيل Embedding rerank الخارجي الموجود من V11:
OPENAI_EMBEDDINGS=on
OPENAI_EMBEDDING_MODEL=text-embedding-3-small
بدون OPENAI_EMBEDDINGS=on سيستخدم local feature-hash semantic memory بدون طلب Embeddings خارجي.

لو تريد Endpoint إداري لقائمة Knowledge Gaps:
ADMIN_API_TOKEN=<another-random-secret>
ثم استدعِ:
GET /api/admin/knowledge-gaps
Authorization: Bearer <ADMIN_API_TOKEN>

لا تضع أي Secret داخل GitHub أو Odoo. ضعها فقط في Vercel Environment Variables.
